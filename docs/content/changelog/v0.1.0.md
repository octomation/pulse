# v0.1.0 — Only what is new.

**First stable release**

Every morning, the trending lists repeat each other and yesterday. pulse folds six of them into one page on your computer that holds only the repositories you have not seen yet. Read it with your coffee, keep what matters in one click, and mark the rest as seen.

## One paper instead of six lists

`pulse` serves a page at <http://pulse.localhost:17842/> that joins the daily, weekly and monthly trends of [trendshift.io](https://trendshift.io/) and [github.com/trending](https://github.com/trending).

```sh
pulse
```

- A repository is one card, whatever number of lists it is in, with its place in each: `trendshift daily #8`, `github weekly #3`.
- The repositories in most lists open the front page; the others are in Today, This week and This month.
- A repository you marked as seen stays hidden when it trends again, a month later too. **Show hidden** shows them, each with the reason.

[The page →](/trend-watch/#the-page)

## Read a repository without leaving the page

Click a repository to open it beside the paper: the stars, the forks, the open issues, the license, the dates of creation and of the last push, the topics and the README as GitHub renders it. `j` and `k` move between repositories, `Esc` closes the reader, and reading marks nothing.

Start pulse with `GITHUB_TOKEN` or `GH_TOKEN` in the environment to read more than about 30 repositories an hour. [The reader →](/trend-watch/#the-reader)

## Keep what matters

**Interesting** bookmarks a repository with an optional comment, **Skip** marks it as seen, and **Mark all shown as seen** clears the page. Export the bookmarks as URLs, one per line, or as JSON lines with the comments:

```sh
pulsectl bookmarks
pulsectl bookmarks --format jsonl
```

[Export the bookmarks →](/trend-watch/#export-the-bookmarks)

## Respect what you already keep

Name the bookmarks directory of your notes vault in `~/.config/pulse/config.toml`, and the repositories its notes name by `url` or `aliases` stay off the page. pulse only reads that directory.

```toml
[vault]
bookmarks = "~/Notes/Bookmarks/GitHub"
```

[Connect your vault →](/trend-watch/#point-it-at-your-bookmarks)

## Calm by design

- Opening the page loads a list at most once an hour; **Refresh** loads all six now.
- A list that fails says so, with its reason, and the others keep working: a failure is never "nothing new".
- pulse listens on `127.0.0.1` and `::1` only and keeps its snapshots, marks and bookmarks as plain files in `~/.local/share/pulse`.

**Install:** on macOS, run `brew install --formula octolab/tap/pulse`. With Go, run `go install go.octolab.org/toolset/pulse/cmd/...@v0.1.0`. For a manual installation, use a [v0.1.0 release archive](https://github.com/octomation/pulse/releases/tag/v0.1.0) for macOS or Linux on `amd64` or `arm64`. Run `pulse version` and `pulsectl version` to check the installed version.
